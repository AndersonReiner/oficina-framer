# Oficina de Prototipacao

Repositório local para preparar uma oficina/apresentação sobre uma ferramenta de prototipação.

## Ambiente

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs --version
```

## Executar localmente

```bash
source .venv/bin/activate
mkdocs serve
```

Depois acesse `http://127.0.0.1:8000`.

O roteiro detalhado, a dinamica e a estrutura da apresentacao serao definidos posteriormente.
