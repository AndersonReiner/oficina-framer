# :material-cursor-default-click-outline: Atividade

Esta pagina concentra a proposta pratica, a avaliacao e os resultados esperados da oficina.

## Proposta pratica

Os participantes deverao desenvolver, em grupo, um prototipo simples no Framer. A atividade deve partir de uma ideia de interface e evoluir para telas organizadas com fluxo de navegacao.

## Etapas sugeridas

- Definir o objetivo da interface.
- Criar um wireframe inicial.
- Inserir elementos visuais basicos.
- Organizar a navegacao entre telas.
- Aplicar ajustes de usabilidade.
- Apresentar o prototipo para a turma.

## Avaliacao

A avaliacao sera continua, considerando:

- Participacao nas atividades propostas.
- Desenvolvimento do prototipo.
- Criatividade e organizacao do projeto.
- Aplicacao de conceitos de usabilidade.
- Apresentacao final da atividade pratica.

## Resultado esperado

Espera-se que os participantes desenvolvam conhecimentos introdutorios sobre prototipacao de interfaces e consigam criar prototipos simples utilizando o Framer.

A oficina tambem pretende incentivar o protagonismo estudantil, o trabalho colaborativo e a troca de experiencias entre academicos.
