# :material-cursor-default-click-outline: Atividade

Esta pagina concentra a proposta pratica, a avaliacao e os resultados esperados da oficina.

## Proposta pratica

Os participantes deverao desenvolver, em grupo, um prototipo simples no Framer. A atividade deve partir de uma ideia de interface e evoluir para telas organizadas com fluxo de navegacao.

## Escolha do projeto

Cada grupo deve escolher **uma** das propostas abaixo. Para evitar que grupos desenvolvam a mesma ideia, a escolha deve ser registrada com o professor antes do inicio da prototipacao.

1. **Agenda de estudos** — organizar disciplinas, tarefas e prazos de um estudante.
2. **Cardapio digital** — consultar produtos, montar um pedido e acompanhar seu status.
3. **Eventos do campus** — descobrir eventos, ver detalhes e confirmar participacao.
4. **Transporte universitario** — consultar linhas, horarios e pontos de embarque.
5. **Doacao de livros** — cadastrar livros, procurar exemplares e combinar uma troca ou doacao.

### Como selecionar

1. Conversem rapidamente e escolham a proposta que o grupo consegue explicar com mais clareza.
2. Confirmem se a ideia cabe em um fluxo curto, com **tres a cinco telas**.
3. Registrem a escolha informando o numero, o nome do projeto e os integrantes do grupo.
4. Se a proposta ja tiver sido escolhida, selecionem outra ou criem uma variacao com objetivo diferente.

Use este modelo para registrar a decisao:

> Grupo: ____________________<br>
> Projeto escolhido: **nº ____ — ____________________**<br>
> Integrantes: ____________________<br>
> Objetivo principal: ____________________

O prototipo deve demonstrar pelo menos um fluxo principal completo, por exemplo: consultar uma informacao, preencher um formulario ou concluir uma acao.

## Etapas sugeridas

- Escolher e registrar uma proposta de projeto.
- Definir o objetivo da interface.
- Criar um wireframe inicial.
- Inserir elementos visuais basicos.
- Organizar a navegacao entre telas.
- Aplicar ajustes de usabilidade.
- Apresentar o prototipo para a turma.

## Avaliacao

A avaliacao sera continua, considerando:

- Participacao nas atividades propostas.
- Desenvolvimento do prototipo.
- Criatividade e organizacao do projeto.
- Aplicacao de conceitos de usabilidade.
- Apresentacao final da atividade pratica.

## Resultado esperado

Espera-se que os participantes desenvolvam conhecimentos introdutorios sobre prototipacao de interfaces e consigam criar prototipos simples utilizando o Framer.

A oficina tambem pretende incentivar o protagonismo estudantil, o trabalho colaborativo e a troca de experiencias entre academicos.
