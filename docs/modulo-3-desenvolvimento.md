# :material-numeric-3-box-outline: Modulo 3 - Desenvolvimento de prototipos

Este modulo concentra a construcao do prototipo e a aplicacao direta da ferramenta.

## Conteudos

- Criacao de wireframes.
- Insercao de elementos visuais.
- Navegacao entre telas.
- Prototipos interativos.

## Objetivo do modulo

Guiar a construcao de uma proposta simples de interface no Framer, partindo da estrutura inicial ate a interacao entre telas.

## Resultado esperado

Ao final deste modulo, os participantes devem conseguir organizar uma pequena interface e transformar a ideia em um fluxo clicavel.
